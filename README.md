# Rajpaul | Application Security Specialist — Portfolio Website

A responsive, dark-themed static portfolio built with HTML, CSS and vanilla JavaScript. It is designed for free hosting on GitHub Pages.

## Files
- `index.html` — all website sections and content
- `style.css` — responsive dark cybersecurity design
- `script.js` — mobile navigation and current year
- `.nojekyll` — tells GitHub Pages to publish the static site as-is

## Before publishing — personal checks
1. Confirm that `4.2 years` is still the experience duration you want to display.
2. Confirm the CEH v11 and eMAPT certification names/status and add verification links only if you have them.
3. Add a professional email address if you want one displayed. The current site directs enquiries to LinkedIn and intentionally does not invent an email address.
4. Replace the sample project cards with your own completed, authorized lab assessments. The cards are explicitly labelled as templates so they are not mistaken for completed client work.
5. Add only sanitized evidence you are permitted to disclose. Do not upload employer/client confidential information or private bug bounty program data.
6. Confirm all links and wording before publishing. GitHub Pages repositories are publicly accessible.

## Publish free with GitHub Pages

### Option A — easiest: create a user site
1. Sign in at https://github.com/.
2. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io` (replace with your GitHub username).
3. Upload `index.html`, `style.css`, `script.js`, and `.nojekyll` from this folder to the repository root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait for the Pages deployment to finish. Your site URL will be `https://YOUR-GITHUB-USERNAME.github.io/`.

### Option B — project site
1. Create a public repository, for example `rajpaul-cybersecurity-portfolio`.
2. Upload the four website files to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, branch **main**, folder **/(root)**, then **Save**.
5. Your URL will be `https://YOUR-GITHUB-USERNAME.github.io/rajpaul-cybersecurity-portfolio/`.

GitHub Pages can take several minutes to publish. Check the **Actions** tab and **Settings → Pages** if the site does not appear.

## Updating the website
Edit the files directly in GitHub using the pencil icon, or replace them with updated versions and commit the changes. GitHub Pages republishes after a commit to the configured branch.

## Important security and privacy notes
- This is a static website. It has no backend, login, database, analytics or contact form.
- Do not put passwords, API keys, private reports, client data, private vulnerability details or other secrets in this repository.
- Use explicit written authorization and agreed scope for all penetration-testing work.
- Keep freelance activity separate from employer systems, accounts and confidential information, and follow applicable employer policies.
